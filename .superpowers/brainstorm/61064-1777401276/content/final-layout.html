Smart UI in this layout:
  • Top bar = command centre — progress bar + cohort pills tell the room how far we are; export/Mark Done always available.
  • Left rail = persistent navigation — list jumps, attention scores at a glance, reviewed items strike-through, search to find a project mid-meeting.
  • Centre = one project, no scroll on common case — header → prompts → signal grid (RAG + chips + since-last-week in 2-row tile pack) → open risks/actions in two columns side by side → tabbed capture (decision · action · risk · comms note in one slot).
  • Right rail = customer pack as you go — headline + wins + asks + visible-risk toggles. Each is annotated with where it lands on the pack ("→ good news slide"). Generate button at the bottom.
  • Bottom bar = momentum stats + keyboard hints — show what was filed in this meeting; Cmd+Enter to advance to next project.
